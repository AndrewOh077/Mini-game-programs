# C++ Mini Programs

A collection of C++ console programs I created while learning and practicing programming fundamentals.

These projects were built to apply concepts such as control flow, arrays, functions, structures, pointers, linked lists, dynamic memory, randomization, and basic game logic.

## Projects

### Maze
A console-based maze game using a 2D array to represent the map.

- Uses structures to store player, start, and destination coordinates
- Handles player movement through the maze
- Uses a 2D character array to represent walls and paths
- Practices array pointers and coordinate-based movement

### Bingo
A 5×5 Bingo game where the player competes against the computer.

- Randomizes player and computer Bingo boards
- Detects completed horizontal, vertical, and diagonal lines
- Includes Easy and Hard computer difficulty
- Hard mode selects numbers based on the computer's current Bingo progress

### Rock Paper Scissors
An interactive console-based Rock Paper Scissors game.

- Generates randomized computer choices
- Accepts keyboard input from the player
- Determines win, loss, and draw conditions
- Uses console colors and ASCII art to create a more visual interface

### Number Baseball
A number guessing game based on the Strike and Ball system.

- Generates a set of numbers for the player to guess
- Compares guesses with the correct answer
- Calculates strikes and balls based on number and position
- Uses functions to separate different parts of the game logic

### Poker Card Distributor
A console program that creates and distributes playing cards.

- Represents a standard deck using arrays
- Randomizes the deck using a shuffle algorithm
- Uses functions to organize card setup, shuffling, and distribution
- Practices array and pointer manipulation

### Puzzle
A console-based number puzzle program.

- Uses arrays to represent the puzzle
- Implements movement and game-state logic
- Uses keyboard input for interaction
- Practices array indexing and conditional logic

### Item Upgrade Game
A probability-based item upgrade simulation.

- Uses randomized success probabilities
- Decreases the success rate as the upgrade level increases
- Changes the upgrade level depending on success or failure
- Uses loops, switch statements, and conditional logic

### Bank Account Program
A basic bank account management simulation.

- Creates and stores multiple accounts
- Searches for account information
- Supports deposits and withdrawals
- Supports transfers between accounts
- Uses structures and arrays to organize account data

### Student Management Program
A student information management system using structures and arrays.

- Registers and deletes student records
- Searches for individual students
- Stores grades and calculates totals and averages
- Assigns letter grades and student rankings

### Student Management Program — Linked List Version
A second student management program built using a singly linked list.

- Dynamically creates student nodes using `new`
- Traverses the linked list to search and display students
- Deletes nodes while maintaining list connections
- Releases dynamically allocated memory using `delete`
- Provides practice with pointers, linked lists, and dynamic memory management

## Concepts Practiced

## Purpose

I created these programs while developing my C++ programming fundamentals and learning how to break larger problems into smaller pieces of logic.

The projects progress from basic control flow and arrays to structures, functions, pointers, and dynamically allocated linked lists.
